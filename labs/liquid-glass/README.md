# EasyMint 液态玻璃调参页

从 `modules/mint-lens/android/src/main/java/em/lens/LensModule.kt` 的 AGSL 源码生成 WebGL 2 材质，默认采用 App 当前的光学参数。输入卡与圆形共用材质，圆形用于观察圆角光影和方向权重。

## 本地启动

在项目根目录执行以下命令。

```bash
python3 labs/liquid-glass/sync-shader.py
python3 -m http.server 8147 --directory labs/liquid-glass
```

浏览器打开 `http://localhost:8147/`。页面使用本地文件，运行时无需下载第三方库。

## 调节和保存

- 28 项参数按形状、主折射、水滴边缘增强、轮廓光影、色散和染色分组。
- 滑杆和数值输入框同步，修改后的参数带标记。
- “对比 App 基线”临时显示默认参数，调参值保留。“恢复 App 参数”恢复默认参数和位置。
- 亮暗主题分别使用 App 的黑色染色基线。聊天、彩色网格和接近纯色三种背景用于比较边缘效果。
- 拖动圆形，或拖动输入卡的 ⠿。方向键也可移动。滚动背景可用下方滑杆、画布上的滚轮或“缓慢滚动”。
- “导出参数”保存 JSON，“导入参数”验证参数类型与范围后恢复。参数文件不包含输入框中的文字。

导出的 JSON 包含参数、主题、背景、玻璃位置和背景滚动位置。可将参数文件交给后续实现任务，用于更新 App。网页调节只影响本页。

## 源码同步

`sync-shader.py` 保留 Android 源码中的形状距离场、曲面法线、双界面折射、左右增强、额外边缘透镜、色散、背景自适应及细边轮廓计算。生成时将关键常量替换为可调 uniform，并检查对应原始表达式是否唯一。

原生公式变化后重新生成 `material.js`。如果同步脚本报告表达式不匹配，应对照 Android 源码更新参数映射和默认值，再生成。生成文件应和脚本一起提交。

## 浏览器与原生的差异

浏览器用 WebGL 双通道 Gaussian 近似原生背景模糊，背景使用 Canvas 绘制的演示内容。原生使用 RenderNode 捕获实际 RN 消息界面。字体、背景图案、采样分辨率、模糊核和裁切细节会影响观感，最终参数仍需真机复核。

页面采用 390 dp 宽的示意场景。输入卡默认高度 98 dp、宽度 358 dp，圆形默认直径 80 dp。App 的实际输入卡尺寸由屏幕宽度和内容决定。

参考设备像素密度默认设为 3.75 物理像素/dp，用于对应这次真机的细边与抗锯齿尺度。它与浏览器画布的实际渲染分辨率分别控制，可在形状分组中调节。
